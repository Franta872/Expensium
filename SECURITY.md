# Security Policy

## Supported versions

The latest release is the supported version.

## Reporting a vulnerability

Please do not publish exploit details in a normal public issue. Use GitHub's private vulnerability reporting feature when available, or contact the maintainer through the contact method on their GitHub profile.

## Security model

Expensium intentionally has a small attack surface: no server component, no remote code, no network requests, no analytics or telemetry, no third-party JavaScript dependencies, only the `storage` permission, and a content script restricted to YouTube.
