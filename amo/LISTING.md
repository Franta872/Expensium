## Name

**Expensium**

## Suggested slug

`expensium`

## Summary

Playfully replace the standard YouTube or YouTube Premium wordmark with Expensium or one of 137 localized variants. Local-only settings and no tracking.

## Description

**Expensium** is a tiny cosmetic Firefox extension for YouTube. It replaces the visible lettering in either the normal YouTube masthead or YouTube Premium masthead while leaving the site's icon and navigation in place.

### Features

- standard YouTube and YouTube Premium support
- Expensium as the English/international default
- 137 playful language variants
- automatic language detection
- searchable language picker
- RTL support
- enable/disable switch
- local-only settings
- no analytics, telemetry, trackers or network API

### AI development disclosure

This project is explicitly **100% vibe-coded**. The implementation and repository setup were generated with OpenAI's ChatGPT under the direction and manual testing of Franta872. The installed extension itself does not call AI services.

### Independent project

Expensium is not affiliated with, endorsed by, sponsored by or officially connected with Google or YouTube. The localized wordmarks are playful pseudo-translations rather than formal dictionary translations.
