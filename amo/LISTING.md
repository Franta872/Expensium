# AMO Listing Copy

## Name
**Expensium**

## Summary
Give standard YouTube an ad-themed wordmark and YouTube Premium an expensive-themed one, with 137 localized variants and no tracking.

## Description

Expensium is a cosmetic Firefox extension for the YouTube masthead.

- Standard YouTube gets an ad-themed joke.
- YouTube Premium gets an expensive-themed joke.
- Auto mode detects which one is visible.
- Users can manually force Standard or Premium.
- 137 languages include both wordmark families.
- No analytics, telemetry, trackers, remote code or network API.

Examples:
- Czech: **Reklamium / Drahium**
- English: **Adium / Expensium**
- German: **Werbium / Teurium**
